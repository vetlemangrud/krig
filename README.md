# krig

Game made with Odin and Raylib. It will be an auto-battler were you build an army of different units. It is loosely inspired by [Blood Tournament](https://www.hiveworkshop.com/threads/blood-tournament-reloaded.353051/), which is a custom map for Warcraft 3.

## Run it

You need [Odin](https://odin-lang.org/)

```bash
odin run .
```
